# МТС · 33 удовольствия — прототип и ТЗ

Кликабельный прототип и техническое задание онлайн-платформы к 33-летию МТС.

**Открыть:** https://vasilievanton.github.io/mts33-prototype/

## О проекте

Платформа с заданиями для сотрудников МТС и дочерних компаний (до 20 000 человек) и страница онлайн-эфира. Концепция — «33 года — все 33 удовольствия»: участник выполняет задания и собирает 33 «удовольствия». Прогресс показан тортом из пяти частей, который «допекается» по ходу праздника. Параллельно участники набирают баллы для рейтинга.

- **Период:** 21.10–11.11.2026, эфир — 28.10.
- **Этапы:** «Готовим торт» (неделя до эфира) → «Задуваем свечу» (день эфира) → «Едим торт» (две недели после эфира).
- **Блоки заданий:** работа и обучение, спорт, творчество, добро, «Работаем вместе», задания-сюрпризы, онлайн-эфир.

## Что внутри страницы

Всё находится в одном HTML-файле без сборки и внешних зависимостей, поэтому его можно открыть просто в браузере. На странице две вкладки:

- **Прототип** — экраны участника: лендинг, регистрация, вход и восстановление пароля, главная, страницы блоков и заданий, прогресс, рейтинг, призы. Демо-панель позволяет сменить дату, войти как гость или участник, переключить вид (компьютер/телефон), включить счастливый час, заполнить или сбросить прогресс.
- **Техническое задание** — путь участника и правила: начисление удовольствий и баллов, реестр заданий, сюрпризы, открытые вопросы. У каждого пункта есть статус: *согласовано*, *на согласовании* или *допущение*.

Прототип и ТЗ строятся из одного блока данных в начале скрипта (`const PROJECT`, `BLOCKS`, `ACTS` и т. д.). Поэтому цифры, даты и тексты в обеих вкладках совпадают, а между экранами и разделами ТЗ есть перекрёстные ссылки.

## Файлы

| Файл | Что это |
|---|---|
| `MTS33_prototip_TZ_v*.html` | Исходник: прототип и ТЗ. Номер в имени — версия; актуальная — с наибольшим номером |
| `docs/` | Опубликованный сайт (GitHub Pages). Не редактировать вручную — его собирает `deploy.sh` |
| `deploy.sh` | Копирует последнюю версию в `docs/index.html` и создаёт переадресации со старых адресов с номером версии |
| `build_md.js` | Собирает из данных прототипа описание проекта в markdown (`MTS33_opisanie_proekta.md`, в репозиторий не попадает) |

## Как внести изменения

1. Отредактируйте актуальный `MTS33_prototip_TZ_v*.html`. Для новой версии скопируйте его со следующим номером и обновите `version` и `updated` в `PROJECT`.
2. Если меняется экран прототипа, обновите и соответствующий текст ТЗ (и наоборот).
3. Запустите `./deploy.sh` (нужен Node.js).
4. Сделайте коммит и пуш в `main`. Через минуту-две GitHub Pages обновит сайт по тому же адресу.

Ссылка на сайт всегда одна и та же. Не давайте ссылки на файлы с номером версии.
